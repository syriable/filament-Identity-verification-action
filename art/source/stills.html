How it works
Verify first. Then run, checked on the server.
The protected form never opens until a scoped grant exists, and every execution re-checks it.
STEP 01
User starts a sensitive action
Change email, change password, delete account, or any action you protect.

The form is not filled or shown. The user confirms their current password instead. Failures are rate limited.

Usage
Protect an action in one line
Inline action
ProtectedAction::make('updateEmail') ->requiresIdentityVerification(purpose: 'update_email') ->schema([ TextInput::make('email')->email()->required(), ]) ->authorize('update', $user) ->action(fn (array $data) => $user->update($data));
Or protect any action class
class VerifiedDeleteAction extends DeleteAction implements ProtectedByIdentityVerification { use RequiresIdentityVerification; }
Install
$ composer require \ syriable/filament-identity-verification-action $ php artisan \ filament-identity-verification-action:install
